# DevClub Store

Site de e-commerce desenvolvido a partir de um tutorial em vídeo do DevClub | Programação, com foco em HTML, CSS e JavaScript, incluindo animações e interatividade.

## Sobre o projeto

Projeto criado para praticar a construção de interfaces web completas, incluindo:
- Estrutura de página com HTML semântico
- Estilização e responsividade com CSS
- Interatividade e animações com JavaScript (carrossel de produtos, indicadores, botões de navegação)

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos e animações
- `scripts.js` — lógica do carrossel e interações
- `img/` — imagens dos produtos

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Status

Concluído, seguindo o tutorial em vídeo.
